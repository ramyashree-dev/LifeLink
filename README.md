\# LifeLink ❤️



\## Blood \& Organ Donation Network



LifeLink is a web-based platform designed to connect blood donors, people requesting blood, hospitals, and organ-donation volunteers.



\## 🌐 Live Demo

https://lifelink-t2fr.onrender.com/

\## 💻 GitHub Repository



https://github.com/ramyashree-dev/LifeLink



\## ✨ Features



\- User authentication

\- Blood donor discovery

\- Blood request creation

\- Donor-request matching

\- Notifications

\- Hospital coordination

\- Organ donation interest registration

\- Supabase authentication and database security



\## 🛠️ Tech Stack



\- React

\- TypeScript

\- Vite

\- Tailwind CSS

\- Supabase

\- PostgreSQL

\- Git \& GitHub

\- Render
